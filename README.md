# Threads substance

A reusable agent skill for deepening **Threads** (or other short social) posts: one claim, grounded evidence, and a reader takeaway—not a link dump or tool list.

Written for Grok Bot / Cursor-style agents. Drop `SKILL.md` into your skills folder (e.g. `threads-substance/SKILL.md`), or point your agent at the raw file.

## Install

1. Clone or copy `SKILL.md` into your agent’s skills directory.
2. Or tell your agent to follow:  
   `https://raw.githubusercontent.com/fred1357944/threads-substance/main/SKILL.md`
